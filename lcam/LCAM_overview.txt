# Park-Do PLAS Research Group · AI City Inc.
# 참고: 2026년 5월 2일 기준 버전 13.2. 방법론은 지속 갱신 중.
#
# 이 문서는 LCAM의 개요입니다.
# Phase 0~8 상세 명세(전문)는 논문 게재 후 공개됩니다.

================================================================
LCAM 개요 (Overview)
================================================================

LCAM은 판결문의 법리적 완전성을 정량적으로 평가하는 범용 방법론이다.
민사·형사·행정·노동·가사·지식재산·헌법 전 법 분야에 적용 가능하다.

================================================================
설계 원칙 4가지
================================================================

1. 보편성: 전 법 분야 적용 가능
2. 정밀성: 9개 논리 오류 유형, 13개 감산 규정 알고리즘화
3. 평가자 재량 최소화: Phase 0 자동 연동, Phase 1.5 자동 설정
4. 재현 가능성: 모든 판정 근거를 판결문 쪽수·문장 단위로 명시

================================================================
전체 구조: Phase 0~8
================================================================

Phase 0  사건 기본 정보 및 자동 연동 (Q0.1~Q0.13)
Phase 1  논리 오류 탐지 (9개 유형)
Phase 1.5 자동 연동 규칙 (은유적 오류 → 법률 없는 권리 창설)
Phase 2  5대 영역 평가 (31개 항목)
Phase 3  13개 공통 감산 규정 적용
Phase 4  중복 방지 검토 (6개)
Phase 5  심급별 차등 가중치 적용
Phase 6  최종 점수 산출
Phase 7  분야별 필수 모듈 적용 (A~G)
Phase 8  최종 보고서 및 평가자 고지

================================================================
5대 평가 영역
================================================================

영역 I   공정성   (무기대등·석명의무·취약자 보호)
영역 II  객관성   (편향 없는 사실 인정)
영역 III 합리성   (삼단논법 완결성·논리 오류 부재)
영역 IV  사실정확성 (증거 기반 사실 인정)
영역 V   법적정당성 (규범 위계 준수·법원칙 적용)

================================================================
9개 논리 오류 유형 및 감산 배점
================================================================

① 순환 논증                  -5점
② 자기실현적 예언             -5점
③ 인과관계 역전              -4점
④ 법률 없는 권리 창설        -10점  ← 최고 감산 (법률유보 위반)
⑤ 허위 딜레마                -3점
⑥ 구성주의 오류              -3점
⑦ 형식적 오류                -4점
⑧ 귀납적 오류                -3점
⑨ 은유적 오류                -2점  ← Phase 1.5 연동 트리거

================================================================
Phase 0 자동 연동의 핵심 기여
================================================================

Q0.1~Q0.13의 13개 질문에 대한 답변이 이후 모든 Phase에
자동으로 연동된다.

예시:
  Q0.8(원고 자원수준) = 취약
  → 석명의무(I-3) 필수 검토 자동 연동
  → 취약 당사자 보호의무(⑪) 필수 검토 자동 연동
  → I-2(무기대등 원칙) 2점 이하 권고 자동 연동

이 설계는 Rawls의 차등 원칙의 방법론적 구현이다.

================================================================
국제 기준 대응
================================================================

영역 I  ← WJP Rule of Law Index Factor 7, CEPEJ 사용자 중심 평가
영역 II ← WJP Factor 7, CEPEJ 성과 평가
영역 III ← WJP Factor 1·3
영역 IV ← CEPEJ 증거 기반 판단
영역 V  ← WJP Factor 4, OECD 사법 변혁 프레임워크

================================================================
재현 가능성
================================================================

LCAM은 법제처 공개 판례에 적용 가능하다.
심사관·독자는 새로운 판례에 LCAM을 적용하여
본 논문의 주장을 독립적으로 검증할 수 있다.

전체 채점 기준(Phase 0~8 상세)은 논문 게재 후 공개된다.
