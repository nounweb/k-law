합의심·전원합의심: 다중 LLM 토론·합의 메커니즘

4.1 왜 여러 AI가 함께 판단해야 하는가

단 하나의 AI 모델은 편향을 가진다. K-Law는 이 문제를 이종(異種) 다중 LLM 구조로 해결한다. 복수의 독립된 AI 모델이 각자 판결을 생성한 뒤 토론과 합의를 거치면, 개별 모델의 편향이 상쇄되어 더 정확한 결론에 도달할 수 있다.

4.2 합의심 — 3개 이종 LLM의 대립과 합의

합의심 진행 5단계

① 3개 모델이 각자 독립적으로 K-Law 방법론에 따라 판결을 생성한다.

② 각 모델의 판결을 교차 제시하고, 쟁점별로 의견이 다른 부분을 자동 식별한다.

③ 의견이 다른 쟁점에 대해 각 모델이 법리적 반론을 제시한다.

④ 다수결 또는 합의에 의해 최종 결론을 도출한다.

⑤ 전 과정이 사용자에게 실시간으로 공개된다.

4.3 전원합의심 — 12개 이상 이종 LLM, 4개 성향군 구성

성향군법철학 지향역할
진보 성향군 (3개)실질적 정의, 취약계층 보호 우선결과의 사회적 형평성 검토
보수 성향군 (3개)제도 안정성, 법적 예측 가능성 우선선례·법문 일치성 검토
인권 성향군 (3개)절차적 공정성, 기본권 보호 우선적법절차·무기대등 검토
법리 성향군 (3개)규범 위계, 엄격 해석 우선법령 체계 정합성 검토

4.4 '만장일치 불일치'의 법학적 의미

12개 이상의 이종 AI가 만장일치로 도달한 결론이 실제 대법원 판결과 다르다면, K-Law의 정확도가 충분히 높아지면 이 불일치는 "법리적 쟁점의 발견" — 현행 판례가 재검토될 필요가 있다는 신호 — 로 기능할 수 있다.

핵심 요약: 일반 LLM은 단일 응답만 가능하다. K-Law는 합의심(3개 LLM, ~90%)과 전원합의심(12개+ LLM, ~99%)으로 편향을 교차 교정하는 법원 심급 구조를 AI로 구현한다.
차이 ⑤

사건 중요도·복잡도 기반 1~3심 자동 배정

5.1 모든 사건이 전원합의심이어야 하는가

현실의 사법 체계에서 소액 사건은 단독 판사가, 중요 사건은 합의부가, 법령 해석 통일이 필요한 사건은 대법원이 담당한다. K-Law도 동일한 원리로 사건을 자동 배정한다.

5.2 CCE — 사건 복잡도 자동 측정

CCE가 측정하는 5가지 복잡도 지표

① 법률관계의 중층성: 계약·불법행위·파산·헌법이 교차하는 정도

② 당사자의 수와 이해관계 구조: 다수 당사자·집단소송·공익 관련 여부

③ 취약 당사자 존재 여부: 경제적·절차적 취약성 (Q0.8 연동)

④ 특별법·헌법 쟁점 존재 여부: 규범 위계 충돌 발생 가능성

⑤ 새로운 법리 필요성: 기존 판례로 해결 불가한 쟁점 존재 여부

CCE 점수배정 심급AI 구성예상 일치율소요 시간
낮음 (단순)단독심 (1심)단일 LLM + 역방향 추론~80%약 5분
중간 (보통)합의심 (2심)3개 이종 LLM + 토론~90%약 20분
높음 (복잡)전원합의심 (3심)12개+ 이종 LLM + 성향군 합의~99%약 60분
핵심 요약: 일반 LLM은 모든 사건에 동일하게 응답한다. K-Law는 CCE 복잡도 측정으로 사건을 1~3심에 자동 배정하여 사법 자원을 최적화한다.
