서론

같은 AI인데, 왜 다른가

'ChatGPT에게 법률 질문을 하면 되지 않나요?' 많은 사람들이 이렇게 묻는다. 틀린 말은 아니다. ChatGPT, Claude, Gemini, DeepSeek은 모두 법률 지식을 보유하고 있고, 간단한 법률 정보를 제공하는 데 유용하다. 그러나 실제 분쟁을 해결하고, 법원 판결에 준하는 결론을 도출하고, 증거의 진위를 확인하고, 편향 없이 공정한 판단을 내리는 것은 전혀 다른 문제이다.

비유하자면 이렇다. 일반 LLM은 "법률을 많이 공부한 박식한 대화 상대"이다. 반면 K-Law는 "법원 판결 절차를 실제로 수행하도록 설계된 시스템"이다. 방법론이 있고, 심급이 있고, 편향 통제 메커니즘이 있고, 증거 검증 인프라가 있다. 둘의 차이는 "의학 지식이 많은 사람"과 "진단 프로토콜을 따르는 의료 시스템"의 차이와 같다.

이 소책자는 K-Law를 일반 LLM과 구분짓는 7가지 핵심 차이를 구체적으로 설명한다.

Openhash 기반 증거·증언의 1초 사실 확인

1.1 현재 법원의 가장 큰 병목: 사실 확인

법원에서 가장 많은 시간이 걸리는 것은 법리 판단이 아니다. "무슨 일이 있었는가"를 확인하는 사실 확인 과정이다. 계약서가 진짜인지, 상대방이 실제로 그 말을 했는지, 금전이 언제 이체되었는지를 두고 당사자들은 수개월간 다툰다. 일반 LLM에게 이 문제는 해결 불가능하다.

1.2 Openhash Private Data Vault (PDV)의 원리

K-Law 시스템은 Openhash 기술과 결합된다. Openhash PDV는 쉽게 말해 '내가 나를 증명하는 자기 증명 시스템'이다. 데이터 원본은 생산자(본인)가 직접 보유하고, 해당 데이터의 해시값만 네트워크 노드의 해시 체인에 기록된다. 분쟁 시 원본 데이터와 해시값이 일치하면 위변조 없음이 증명된다. 둘 중 하나라도 없으면 증명이 불가능하다.

Openhash의 3가지 법적 의미

① 위변조 불가능성: 데이터 원본은 본인만 보유하고, 해시값이 노드 해시 체인에 기록된다. 원본과 해시가 모두 존재할 때만 위변조 없음을 입증할 수 있다.

② 타임스탬프 확정: 해시 체인에 기록된 순간의 시각이 변경 불가능하게 확정되므로 "언제" 발생했는지가 증명된다.

③ 자기 증명 구조: Openhash는 '내가 나를 증명하는' 수단이다. 둘 중 하나라도 없으면 증명이 불가능하다.

1.3 1초 사실 확인이 바꾸는 것

단계일반 법원 (현재)K-Law + Openhash

계약 진위 확인서류 감정·필적 비교 → 수주원본 + 해시값 일치 확인 → 즉시
이체 사실 확인금융거래정보 제출명령 → 수개월이체 원본 + 해시 체인 타임스탬프 → 즉시
증언 신빙성증인 교차 심문 → 불확실원본과 해시 체인 불일치 시 위변조 자동 탐지
법리 적용판사가 수주~수개월 작업K-Law 방법론 → 약 5분
