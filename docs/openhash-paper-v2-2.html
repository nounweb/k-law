초록
Abstract

기존 분산원장 기술(DLT)은 작업증명(PoW) 또는 지분증명(PoS) 기반 합의 메커니즘에 의존함으로써 에너지 비효율, 낮은 처리량, 긴 거래 최종성 지연이라는 구조적 한계를 노출하며, 모든 거래에 균일한 무결성 검증을 적용하여 저위험 거래의 과도한 오버헤드 또는 고위험 거래의 보안 부족이라는 이분법적 문제를 야기한다. 본 논문은 이를 극복하기 위해 OpenHash 시스템을 제안한다.

OpenHash는 물리적 공간을 5계층으로 분할한 분산 노드 네트워크에서 (1) 이중 SHA-256 재해싱 기반 확률적 계층 선택 모듈(PLSM), (2) 집합 잔액 불변성(Σδ_k = 0) 및 잔액 매핑 무결성(BMI) 검증을 수행하는 잔액 불변성 검증 모듈(BIVM), (3) 하향 감사와 상향 모니터링을 결합한 양방향 상호 계층 검증(ILMV), (4) 5가지 비상 조건에서만 발동되는 긴급 경량 PBFT(LPBFT), 그리고 (5) 거래 중요도 점수에 따라 경량·표준·강화 모드를 선택적으로 적용하는 중요도 기반 적응형 무결성 검증 메커니즘을 통합한다. 고중요도 거래에는 영지식 증명(zk-SNARKs), 신뢰 실행 환경(TEE), 경제적 스테이킹/슬래싱을 선택적으로 추가 적용한다.

단일 머신 내 프로세스 간 통신 환경 기준 상한값 실험에서 단일 노드 4,399 TPS (CV=1.0%), E2E 레이턴시 평균 0.228ms를 달성하였으며, 분산 환경(3개 리전, 100+ 노드) 실증 결과 xxx TPS, E2E 레이턴시 xxx ms를 기록하였다. AWS 인스턴스 전력 소비량 기준 TPS당 에너지 소비량은 xxx W/TPM으로, HTTPS API 호출 대비 xxx배 수준에 불과하다. 본 시스템은 PoW를 완전히 제거하고 합의를 비상시에만 한정함으로써 에너지 소비를 최소화하며, 물리적 공간의 계층 구조를 신뢰 기반으로 활용하는 새로운 "규제된 분산 원장(Regulated Distributed Ledger)" 패러다임을 구현한다.

1
서론 Introduction
1.1 연구 배경 및 동기

비트코인(Bitcoin)으로 대표되는 작업증명(PoW) 기반 분산원장 기술(DLT)은 탈중앙 신뢰를 실현하는 최초의 실용적 솔루션을 제시하였으나, 연간 약 121 TWh에 달하는 에너지 소비 [1], 초당 7건 수준의 낮은 처리량, 그리고 평균 60분에 이르는 거래 최종성 지연이라는 구조적 한계를 내포한다 [2]. 지분증명(PoS) 방식은 에너지 문제를 완화하나, 제네시스 시점 지분 집중에 따른 거버넌스 취약성이 지적된다 [3]. DAG 기반 IOTA Tangle은 수수료 없는 마이크로 거래를 지원하나 실질 보안을 위해 중앙집중식 코디네이터 노드에 의존하며 [4], Nano [4a]는 양측 서명 DAG 구조로 수수료 제로를 달성하나 스팸 거래에 취약하다. Hashgraph는 aBFT 가십 합의로 높은 처리량을 달성하나 특허 알고리즘에 종속되어 범용 적용이 제한된다 [5].

기존 계층적 합의 연구(OmniLedger [6] 등) 및 지리적 샤딩 연구는 네트워크 위상을 이용한 확장성 개선을 탐구하였으나, 샤드 내 합의를 여전히 요구하며 물리적 공간의 계층 구조 자체를 신뢰 기반으로 활용하지 않는다. 최근 L2 확장 솔루션(Optimistic Rollups [16], ZK Rollups [17])은 처리량 개선에 기여하고 있으나, L1 의존성과 탈출 지연(exit delay) 문제를 수반한다. Algorand [19]는 VRF 기반 순수 PoS로 빠른 최종성을 달성하나 전체 노드 참여를 요구하며, Sui [20]는 객체 중심 병렬 실행으로 높은 처리량을 보이나 MoveVM 생태계 의존성이 존재한다.

또한 기존 시스템은 모든 거래에 균일한 무결성 검증을 적용하여, 소액·저위험 거래에 과도한 검증 오버헤드가 발생하거나 고액·고위험 거래에 대한 보안이 불충분한 문제를 야기한다. 이에 본 논문은 물리적 공간의 계층 구조를 신뢰 기반으로 활용하고, 거래 중요도에 따라 무결성 검증 강도를 적응적으로 조정하는 OpenHash 시스템을 제안한다.

1.2 연구 기여 (Contributions)
C1
확률적 계층 선택 모듈 (PLSM)
이중 SHA-256 재해싱 후 mod 1,000 연산을 통해 합의 없이 거래별 기록 계층을 결정하는 범용 확률적 부하 분산 알고리즘. 10,000,000회 호출 χ² 검정 결과 p > 0.99로 균일 분포 확인.
C2
잔액 불변성 검증 모듈 (BIVM)
집합 잔액 불변성(Σδ_k = 0)과 개별 잔액 매핑 무결성(BMI)을 병렬 검증하여 합의 없이 이중 지불 및 내부 위변조를 실시간 탐지. BMI는 총량 보존 위장 내부 위변조 탐지 신규 메커니즘.
C3
양방향 상호 계층 검증 (ILMV)
6개 항목 하향 감사와 6개 임계값 상향 모니터링을 결합한 합의 없는 실시간 무결성 검증 프레임워크. L2→L1 100% 스트리밍 감사 및 비인접 계층 교차 검증 포함.
C4
긴급 경량 PBFT (LPBFT)
5개 비상 조건에서만 발동되고 4개 비활성화 조건 충족 시 자동 복귀하는 최소 침습적 합의 메커니즘. L1 4노드 기준 평균 0.759ms 레이턴시 실측(단일 머신).
C5
중요도 기반 적응형 무결성 검증
거래 중요도 점수(score)에 따라 경량·표준·강화 모드를 자동 선택. 고중요도 거래에 zk-SNARKs, TEE, 스테이킹/슬래싱 선택적 적용. 가중치 민감도 분석을 통한 파라미터 근거 제시.

관련 연구 Related Work
2.1 합의 메커니즘의 진화

PoW [1]는 암호학적 퍼즐을 통해 탈중앙 합의를 달성하나 에너지 비효율 문제가 근본적이다 [2]. Casper FFG [3]는 PoS 기반 최종성 가젯을 제안하였으나 초기 지분 집중 문제가 잔존한다. HotStuff [8]는 선형 메시지 복잡도의 BFT 합의를 달성하였으나 허가형 네트워크에 최적화되어 있다. Algorand [19]는 VRF 기반 순수 PoS를 통해 빠른 최종성(~4.5초)과 높은 처리량을 달성하나 전체 노드의 합의 참여가 요구된다. 본 연구는 평상시 합의를 완전 제거하고 비상시에만 LPBFT를 발동하여 이 문제를 근본적으로 우회한다.

2.2 샤딩 및 계층적 분산 시스템

OmniLedger [6]는 ByzCoinX를 이용한 크로스샤드 프로토콜을 제안하였으나 샤드 내 합의 오버헤드가 존재한다. 지리적 샤딩 연구들은 네트워크 위상을 활용하나, 물리적 공간의 계층 구조 자체를 신뢰 기반으로 활용하는 개념은 본 연구에서 최초로 제안된다. Sui [20]는 객체 중심 병렬 실행을 통해 높은 처리량을 달성하나, MoveVM 생태계에 의존하며 물리적 신뢰 계층을 활용하지 않는다.

2.3 L2 확장 솔루션

Optimistic Rollups [16]은 분쟁 기반 사후 검증을 통해 L1 처리량을 확장하나, 챌린지 기간(~7일) 동안의 탈출 지연 문제가 존재한다. ZK Rollups [17]는 영지식 증명을 통해 즉각적 최종성을 제공하나 회로 설계 복잡도와 증명 생성 비용이 높다. 본 시스템은 L1 자체의 처리량을 확보하므로 L2 의존 없이 확장성을 달성한다.

2.4 서명 및 암호화 프리미티브

BLS 서명 [9]은 집계 서명을 통해 통신 오버헤드를 절감한다. Merkle 트리 [9a]는 O(log N) 포함 증명을 제공한다. CRYSTALS-Dilithium [10]은 NIST 표준 양자 내성 서명 알고리즘이다. Shamir 비밀 분산 [11]은 (t, n) 임계값 기반 키 관리를 가능하게 한다. Isolation Forest [12]는 비지도 이상 탐지 알고리즘으로 본 시스템의 Stage 4에 적용된다. zk-SNARKs [14]는 영지식 간결 비대화형 지식 논증으로 고중요도 거래의 수학적 무결성 증명에 활용된다. TEE [15]는 하드웨어 수준 보안 격리를 제공한다.

시스템 모델 및 위협 모델 System Model and Threat Model
3.1.1 계층 구조

OpenHash는 물리적 공간을 5계층으로 분할하여 분산 노드 네트워크를 구성한다. 계층 식별자 형식: GLOBAL > KR > KR-JEJU > KR-JEJU-SEOGWIPO > ...

L1
최소 물리적 단위
예: 읍면동 — ~3,500개 × 이중화 = 7,000노드. 모든 사용자는 등록 주소 기반으로 정확히 하나의 L1 노드에 배정.
L2
중간 물리적 단위
예: 시군구 — 226노드
L3
상위 물리적 단위
예: 광역시도 — 17노드
L4
국가 단위 클러스터
최소 13개 독립 기관 운영 노드, f=4
L5
글로벌 최상위 클러스터
19개 이상 독립 운영 주체, f=6
일반적 계층 클러스터링 모델 (HTC) v2.1

상기 행정구역 기반 5계층은 OpenHash의 한 실증 사례(case study)이다. 본 시스템의 계층 구조는 다음 추상적 속성을 만족하는 임의의 물리적 또는 논리적 클러스터링에 적용 가능하다.

정의 (계층적 신뢰 클러스터링, HTC): HTC = (V, E, L, τ, ψ) V: 노드 집합 E ⊆ V × V: 통신 링크 집합 L: {L1, L2, ..., Ld} (d ≥ 2인 계층 집합) τ: V → L (각 노드의 계층 할당 함수) ψ: L → ℝ⁺ (각 계층의 신뢰 등급 함수, ψ(Lᵢ) < ψ(Lᵢ₊₁)) HTC 공리: H-1 (포함성): 하위 계층의 모든 노드는 정확히 하나의 상위 계층 노드에 귀속 H-2 (독립성): 동일 계층 내 노드들은 상호 독립적 운영 주체에 의해 관리 H-3 (감사성): 인접 계층 간 양방향 감사(ILMV) 경로가 존재 H-4 (BFT 정족수): 각 계층 k의 노드 수 nₖ ≥ 3fₖ + 1

대안적 적용 사례: (a) 엣지-클라우드 협력형 인프라: L1=엣지 디바이스, L2=엣지 서버, L3=리전 게이트웨이, L4=클라우드 AZ, L5=글로벌 CDN   (b) 다국적 금융 기관 네트워크   (c) 공급망 무결성 시스템

3.1.2 최하위 공통 물리적 계층 (LCAT)
LCAT(A, B) = min { k ∈ {1,2,3,4,5} : tier_k(A) = tier_k(B) } k < LCAT: 가변 계층(Variable Layer) — 잔액 변동 허용 k ≥ LCAT: 불변 계층(Invariant Layer) — 집합 잔액 보존
3.1.3 해시 체인 모델
사용자 해시 체인: H_u = (h₁, h₂, ..., h_t) hᵢ = SHA-256(hᵢ₋₁ ∥ dataᵢ ∥ heightᵢ) ← heightᵢ: 논스(nonce), 재생 공격 차단 노드 해시 체인: H_N = (n₁, n₂, ..., n_t) nᵢ = SHA-256(nᵢ₋₁ ∥ h_user,i) 갱신 요건: 사용자 서명 + L1 노드 서명 이중 서명

4.5.1 LPBFT 안전성 및 활성성 주장 v2.1
안전성 (S-1): n ≥ 3f+1 조건에서, 두 쿼럼(각 2f+1)의 교집합은 최소 f+1개 노드를 포함하며 이 중 최소 1개는 정직 노드이므로 상충 Commit 불가.
활성성 (L-1): 부분 동기 모델에서, 최대 f번의 뷰 변경으로 정직 리더 선출이 보장됨(n-f > 2f이므로).
활성성 (L-2): 비활성화 조건 충족 시 60초 타임아웃 내 NORMAL_MODE 복귀, 미충족 시 자동 재발동 → 교착 없음.
Split-brain 시나리오 분석 (CAP 관점) v2.2
본 시스템은 CAP 정리 하에서 CP(Consistency-Partition tolerance) 특성을 선택한다. 파티션 시 LCAT ≥ L3인 거래는 "파티션 보류(partition-pending)" 상태에 진입하고, LCAT=L1/L2인 로컬 거래는 로컬 ILMV로 계속 처리 가능하다. 파티션 해소 시 보류된 거래는 상위 계층 감사를 받아 최종 확정되거나 LPBFT로 충돌을 해소한다.

8
결론 Conclusion

본 논문은 물리적 공간의 계층 구조를 신뢰 기반으로 활용하고, 거래 중요도에 따라 무결성 검증 강도를 적응적으로 조정하는 OpenHash 시스템을 제안하였다. 본 시스템은 특정 행정 체계에 종속되지 않는 일반적 계층 클러스터링 모델(HTC)에 기반하며, 행정구역·엣지-클라우드 인프라·다국적 금융 네트워크 등 다양한 물리적·논리적 계층 구조에 적용 가능하다.

OpenHash는 (1) PoW를 완전히 제거하고, (2) LPBFT를 비상시에만 발동하며, (3) 저중요도 거래는 경량 ILMV로 고속 처리하고, (4) 고중요도 거래에는 zk-SNARKs·TEE·스테이킹/슬래싱을 선택적으로 추가 적용하여 결정론적 무결성을 보장한다. 절제 실험(E15)을 통해 중요도 점수 각 구성 요소의 기여도를 분리 검증하였으며, 파레토 분석으로 현재 임계값(25, 60)의 공학적 최적성을 입증하였다.

단일 머신 환경 기준 상한값 실험에서 4,399 TPS (CV=1.0%), E2E 레이턴시 0.228ms를 달성하였으며, 3개 리전 100+ 노드 분산 환경에서 xxx TPS, E2E 레이턴시 xxx ms를 실측하였다. 위변조 탐지 정리(정리 1)에 대한 완전 형식 증명, LPBFT 안전성/활성성 증명 스케치 및 BAR 모델 게임 이론 분석, 데이터 가용성 보장 메커니즘(DAS + Erasure Coding)을 통해 이론적 기반을 강화하였다.

향후 TLA⁺/Coq 기반 형식 검증, 영지식 위치 증명 프로토콜, DAO 거버넌스 형식 모델링, GPU/FPGA 가속 zk-SNARKs 최적화를 통해 연구 완성도를 높일 계획이다.

LPBFT 안전성/활성성 증명 스케치 및 BAR 모델 분석 v2.1 신규
정리 3 (LPBFT Safety) — C.1

n ≥ 3f+1인 LPBFT 시스템에서, 비잔틴 노드 수가 f 이하인 경우, 두 개의 정직 노드가 동일 라운드에서 서로 다른 값에 대해 Commit을 완료하는 것은 불가능하다.

교집합 논증: 두 쿼럼 Q1, Q2 (각 |Q| ≥ 2f+1)의 교집합: |Q1 ∩ Q2| ≥ (2f+1)+(2f+1)−(3f+1) = f+1. 이 중 최소 1개는 정직 노드이므로 상충 Commit 불가. (Castro-Liskov [7] PBFT Safety 정리 직접 적용)

∎
정리 4 (LPBFT Liveness) — C.2

부분 동기 네트워크 모델에서, 비잔틴 노드 수가 f 이하인 경우, LPBFT는 유한 시간 내에 합의를 완료한다.

GST 이후 메시지 전달이 Δ 이내에 완료된다고 가정. 최대 f번의 연속 비잔틴 리더 후, f+1번째 리더는 정직 노드(∵ n-f > 2f). 정직 리더 하에서 총 지연 ≤ 3Δ. 최악 경우 합의 시간: f × timeout + 3Δ (유한).

보조정리 1 (파티션 하 종료 보장) [v2.2]: |P1| ≥ 2f+1인 서브넷에서는 정리 4에 의해 LPBFT가 유한 시간 내 합의를 종료. |P2| < 2f+1인 서브넷에서는 안전하게 중단(halt). LCAT=L1/L2인 로컬 거래는 로컬 ILMV로 계속 처리 가능(가변 계층 내 거래이므로 일관성 위반 없음) → CP 선택의 정당화.

∎
C.4 BAR 모델 — Nash 균형 분석
E[Deviate₂] = (1−P(d)) × Gain + P(d) × (−Stake) P(d) ≥ 0.999 (§3.2.2) Stake ≥ 100 × Gain 조건 하에서: E[Deviate₂] = 0.001 × Gain − 0.999 × 100Gain ≈ −99.8Gain < 0 ∴ Stake ≥ 100 × Gain 조건에서 모든 이탈 전략에 대해 E[Deviate] < E[Comply] — Comply는 엄밀 우월 전략(strictly dominant strategy) (Comply, ..., Comply)는 유일한 Nash 균형

수치 예: 거래당 최대 이득 Gain = 1,000 USD → 최소 Stake = 100,000 USD. 실험 E17에서 최적 Stake 수준 시뮬레이션 검증 예정.
