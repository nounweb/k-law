# IDDM: Illegality Detection & Deterrence Methodology
# 고팡 소통 위법성 자동 감지 및 예방방법론
# Park-Do PLAS Research Group · AI City Inc.
# 적용 범위: Gopang 플랫폼을 통해 오가는 모든 대화·문서·데이터

================================================================
중요 고지
================================================================

이 방법론은 소통 내용의 위법성 가능성을 자동으로 평가하는
분석 도구이다. 법원 수준의 유죄 판결이 아니며,
사용자에게 최종 결정권이 있다.

OpenHash에 기록된 데이터는 오직 당사자 본인만 접근할 수 있다.
법원 영장으로도 강제 압수·수색이 불가능하다.
IDDM은 타인의 유죄를 발각하는 수단이 아니다.
IDDM은 당사자가 자신의 무죄·정당성을 스스로 입증하는
자기 방어적 증거 보전 수단이다.

================================================================
Phase 0: 소통 객체 식별 (강제)
================================================================

Q0.1 소통 유형: 텍스트/문서/음성/복합
Q0.2 발신자 유형: 개인/기관AI/외부서비스/시스템
Q0.3 수신자 유형: 개인/기관AI/외부서비스/그룹
Q0.4 소통 맥락: 신규/연속/계약·거래/민원/금전/의료·법률/기타
Q0.5 첨부 파일 여부: 예→Phase 2 병렬처리 / 아니오→Phase 1
Q0.6 채널 암호화 정상 여부: 비정상→즉시 S3
Q0.7 AI 신원 검증 (AI간 소통 시): 실패→즉시 S3
Q0.8 발신자 위험 이력 (30일): 있음→가중치 1.3

================================================================
Phase 1: 형태소 분석 및 의미 단위 분해
================================================================

1.1 전처리
  - 유니코드 정규화 (NFC)
  - 특수문자·이모지 처리 (법적 위험 관련 이모지 태깅)
  - 축약어·은어·줄임말 확장
  - 외래어·영문 혼용 병렬 처리

1.2 Fast-Path (고위험 즉각 처리)
아래 트리거 해당 시 Phase 1.3~3을 건너뛰고 즉시 판정:

  FP-01: 금융기관·검찰·경찰 사칭 명시 → score=1.0, S3
  FP-02: 계좌번호·OTP·비밀번호 즉시 요구 → score=0.95, S3
  FP-03: 긴급 송금 요구 + 금액 명시 → score=0.90, S3
  FP-04: 불법 도박·유사수신 권유 → score=0.85, S2
  FP-05: 직장 내 괴롭힘·성희롱 명시 → score=0.80, S2
  FP-06: 협박·공갈 명시 → score=0.90, S3
  FP-07: 아동·청소년 대상 위험 → score=1.0, S3 + 수사기관 안내
  FP-08: 자해·자살 위기 표현 → score=1.0, S3 + 복지 연계

1.3 Context-Path (맥락 기반 정밀 분석)
  - 의도 분류: 정보요청/행동요구/감정표현/협상/위협/기망/기타
  - 위험 키워드·패턴 탐지 (법령 분류별 DB 매칭)
  - 맥락 조합 분석 (직전 5개 SU 참조)

================================================================
Phase 2: 법령 분류별 위험 지표 평가
================================================================

[형사 위험 지표 CR-1~CR-5]
CR-1 사기·기망: 허위 신원/금전 이전 유도/착오 이용
CR-2 협박·공갈: 조건부 불이익/공개 빌미 이익 요구
CR-3 명예훼손: 사실 주장/공연성/허위 여부
CR-4 도박: 금전 우연 득실/불법 플랫폼 유도
CR-5 개인정보: 무단 수집 요구/제3자 제공

[민사 위험 지표 CV-1~CV-4]
CV-1 불공정 계약: 약관규제법 위반/현저한 불균형/필수 기재 누락
CV-2 임대차 위법: 주택임대차보호법 위반/보증금 거부/법적 권리 침해
CV-3 불법 이자: 이자제한법 상한(연 20%) 초과/선이자 편법
CV-4 개인정보·프라이버시 침해

[노동 위험 지표 LB-1~LB-2]
LB-1 직장 내 괴롭힘: 근로기준법 제76의2/업무 범위 초과
LB-2 부당해고·임금: 정당 이유 없는 해고/임금 체불

[소비자 위험 지표 CC-1~CC-2]
CC-1 허위·과장 광고: 표시광고법 위반
CC-2 유사수신·불법 다단계: 유사수신행위규제법 위반

================================================================
Phase 3: 문서·파일 위법성 분석
================================================================

DOC-1 계약서: 불공정 조항/위조 흔적/필수 기재 누락
DOC-2 금융 문서: 금액 위변조/불법 이자율/허위 서명
DOC-3 신분증·공문서: 사진 합성/발급기관 위변조
DOC-4 이미지·동영상: 딥페이크/불법 촬영물/저작권 침해

================================================================
Phase 4: 통합 위험 점수 산출
================================================================

가중치:
  P1_score (형태소·패턴): 0.35
  P2_score (법령 분류):   0.50
  P3_score (문서 분석):   0.15

WS = (P1 × 0.35) + (P2 × 0.50) + (P3 × 0.15)
FINAL_score = WS × Q0.8_weight (1.0 또는 1.3)
              상한: 1.0

쌍방향 검증:
  발신 FINAL_score + 수신 FINAL_score → max값으로 최종 판정

================================================================
Phase 5: 위험 등급 판정 및 처리
================================================================

S0 (정상, score < 0.3):
  정상 전송. PDV 일반 기록.

S1 (경고, 0.3~0.6):
  경고 메시지 표시. 사용자 선택.

S2 (위험, 0.6~0.9):
  3초 지연 + 강력 경고 + 법률 상담 권고.
  PDV 자동 기록. 30일 내 재발 시 Q0.8 가중치 1.3.

S3 (긴급, ≥ 0.9 또는 FP-07·FP-08):
  즉시 차단. 관련 기관 안내.
  FP-07: 경찰청 112·여성긴급전화 1366
  FP-08: 자살예방상담전화 1393·정신건강위기상담전화 1577-0199

이의 제기: S2·S3 판정 시 재심사 요청 가능. 재검토 시간 ≤ 3초.

================================================================
Phase 6: PDV 기록 및 OpenHash 등록
================================================================

Step 1: AES-256 암호화 (사용자 개인 키)
Step 2: SHA-256 해시 생성
Step 3: OpenHash 4계층 분산 등록 (BLS 서명)
Step 4: PDV 저장 (사용자만 접근 가능)
Step 5: 증거 인출 (분쟁 시 사용자 승인 → 무결성 검증 → 패키지 생성)
