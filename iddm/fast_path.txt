# Fast-Path 즉각 탐지 목록 (FP-01~FP-08)
# IDDM Phase 1.2
# Park-Do PLAS Research Group · AI City Inc.

================================================================
Fast-Path란?
================================================================

아래 트리거에 해당하는 소통은 Phase 1.3~3을 건너뛰고
즉시 위험 등급을 판정한다.
탐지 속도 목표: ≤ 0.8mS (인간 지각 임계값 이하)

================================================================
FP-01: 금융기관·검찰·경찰 사칭
================================================================

패턴:
  "저는 검사입니다" / "금융감독원입니다" / "경찰청입니다"
  "OO 은행 보안팀" / "금융범죄수사대" 등

판정: FINAL_score = 1.0, 즉시 S3
근거: 형법 제347조(사기), 전기통신금융사기 피해방지법

================================================================
FP-02: 계좌번호·OTP·비밀번호 즉시 요구
================================================================

패턴:
  "계좌번호를 알려주세요" + 금융 맥락
  "OTP를 입력해주세요" / "비밀번호를 확인해드리겠습니다"
  "보안카드 앞 두 자리" 등

판정: FINAL_score = 0.95, S3
근거: 전기통신금융사기 피해방지법, 개인정보보호법

================================================================
FP-03: 긴급 송금 요구 + 금액 명시
================================================================

패턴:
  "지금 바로 송금해주세요" + 금액 명시
  "30분 안에" / "오늘 안에" + 계좌 번호
  "사고가 났어요" + 송금 요청 등

판정: FINAL_score = 0.90, S3
근거: 형법 제347조(사기), 전기통신금융사기 피해방지법

================================================================
FP-04: 불법 도박·유사수신 권유
================================================================

패턴:
  "원금 보장" + 투자 수익률 명시
  "○○ 도박 사이트" / "배팅" + 금전
  "다단계" / "회원 모집" + 수익 구조 설명

판정: FINAL_score = 0.85, S2
근거: 형법 제247조(도박), 유사수신행위규제법 제3조

================================================================
FP-05: 직장 내 괴롭힘·성희롱
================================================================

패턴:
  신체 관련 모욕적 표현 + 직장 맥락
  "○○ 씨는 쓸모없어" + 반복적 모욕
  성적 언어 또는 신체 언급 + 직장 관계

판정: FINAL_score = 0.80, S2
근거: 근로기준법 제76의2조, 남녀고용평등법 제12조

================================================================
FP-06: 협박·공갈
================================================================

패턴:
  "하지 않으면 공개하겠다" / "○○하면 신고하겠다"
  조건부 + 불이익 위협 구조
  "돈을 주지 않으면" + 피해 위협

판정: FINAL_score = 0.90, S3
근거: 형법 제283조(협박), 제350조(공갈)

================================================================
FP-07: 아동·청소년 대상 위험
================================================================

패턴:
  성적 접근 + 미성년자 식별
  "만나자" + 나이 확인 + 성인 발신자
  선물·금전 제공 + 비밀 요구 + 미성년자 맥락
  부모에게 알리지 말라는 지시

판정: FINAL_score = 1.0, 즉시 S3
       수사기관 안내: 경찰청 112, 여성긴급전화 1366
근거: 아동·청소년의 성보호에 관한 법률

================================================================
FP-08: 자해·자살 위기
================================================================

패턴:
  "죽고 싶다" / "사라지고 싶다" + 구체적 방법 언급
  "더 이상 살 이유가 없다" + 절망적 맥락
  자해 방법 질문 / 유서 작성 언급

판정: FINAL_score = 1.0, 즉시 S3
       복지 연계:
         자살예방상담전화: 1393
         정신건강위기상담전화: 1577-0199
근거: 사용자 안전 최우선 원칙

================================================================
Fast-Path 우선순위
================================================================

FP-07·FP-08이 최우선. 이 두 경우는 다른 모든 판정을 무시하고
즉시 S3으로 처리한다.

FP-01~FP-06은 FINAL_score와 max 비교:
FINAL_score = max(WS_계산값, FP_즉시_점수)
